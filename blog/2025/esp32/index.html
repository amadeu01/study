Resolvendo Problemas de Saída Serial Ilegível no ESP32 com PlatformIO

Created on October 19, 2025

2025   ·   esp32   platformio   serial   vscode   arduino   ·   embedded

Projeto: Programação Embarcada com ESP32

Área: Desenvolvimento e Programação

Recurso: Solução de Problemas de Comunicação Serial

Hoje, ao programar um ESP32 (modelo com chip CH340C) usando o Visual Studio Code com a extensão PlatformIO, enfrentei um problema comum, mas frustrante: a saída no monitor serial estava completamente ilegível, exibindo caracteres como ␒!q␚␌␘a 0Щ.

O Problema: Incompatibilidade de Baud Rate

A causa raiz para esse tipo de saída corrompida é quase sempre uma incompatibilidade na taxa de transmissão (baud rate) entre o microcontrolador (ESP32) e o computador que está lendo os dados (o monitor serial do PlatformIO).

O ESP32 inicia sua comunicação serial a uma velocidade definida no código (ex: Serial.begin(115200);), enquanto o monitor serial do PlatformIO escuta em outra velocidade, que por padrão pode ser 9600 ou outro valor. Quando essas duas velocidades não são idênticas, a interpretação dos bits é dessincronizada, resultando em “lixo” na tela.

A Solução: Sincronizar o Baud Rate

Para resolver o problema, é necessário garantir que a velocidade configurada no firmware do ESP32 seja a mesma que a do monitor serial no PlatformIO.

1. Definir o Baud Rate no Código Arduino (.ino ou .cpp):

No seu arquivo de código principal, dentro da função setup(), certifique-se de que a comunicação serial seja iniciada com um valor explícito. A velocidade de 115200 é um padrão robusto e amplamente utilizado para o ESP32.

void setup() {
  // Inicia a comunicação serial na velocidade de 115200 bps
  Serial.begin(115200);

  // Aguarda um momento para a porta serial conectar. Necessário para algumas placas.
  delay(1000);

  Serial.println("Monitor Serial funcionando!");
}

void loop() {
  // Seu código aqui...
}

2. Configurar o monitor_speed no platformio.ini:

Em seguida, adicione a diretiva monitor_speed ao arquivo de configuração do seu projeto PlatformIO para que ele corresponda exatamente ao valor definido no código.

[env:esp32dev]
platform = espressif32
board = esp32dev
framework = arduino
upload_port = /dev/ttyUSB0
monitor_port = /dev/ttyUSB0

; --- LINHA A SER ADICIONADA ---
monitor_speed = 115200

lib_deps = madhephaestus/ESP32Servo@^3.0.9
monitor_dtr = 0
monitor_rts = 0

Após realizar essas duas alterações, basta recompilar e fazer o upload do projeto para o ESP32. Ao abrir o monitor serial, a saída agora será exibida corretamente.
